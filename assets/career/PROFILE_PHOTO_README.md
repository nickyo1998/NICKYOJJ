# Profile photo asset

Replace `profile-photo.jpg` with your preferred professional headshot whenever you want to update the Executive Profile photo.

- Keep the filename exactly as `profile-photo.jpg`.
- Use a vertical portrait, ideally at least 1200 pixels tall.
- Leave this image in the `assets/career/` folder.

The website crops the image automatically. The hero now uses `hero-team.png`, so this profile image is intentionally reserved for the Executive Profile section.
